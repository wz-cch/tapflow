# TapFlow ‧ 觸控流

Android 按鍵精靈:錄製你的觸控操作並自動重播。**不需要 root**,靠無障礙服務(`AccessibilityService`)實現。

純 Kotlin + Jetpack Compose。自用側載,不上 Google Play。

> **完整規格見 [docs/SPEC.md](docs/SPEC.md)** —— 資料模型、狀態機、互動設計、分期計畫都在裡面。
> 開發慣例(Git Flow、commit 格式、程式碼與語系規則)見 [CONTRIBUTING.md](CONTRIBUTING.md)。

---

## 它長什麼樣

螢幕上浮著一排工具列。按錄製,你的每個觸控被記下來,同時真的送到下層 app 讓畫面前進;
錄完,每一步變成螢幕上一個可拖曳的準心或曲線,你直接拖就改座標;
錄到需要輸入驗證碼那種地方,插一個**暫停點** —— 跑到這裡自動停,你手動處理完按繼續;
滿意了按儲存變成一個**片段**;多個片段可以串成一條**流程**;
按播放,它照著跑。

三個懸浮視窗:

- **左側垂直工具列** — 播放 / 錄製 / 插暫停點 / 復原 / 編輯模式 / 儲存 / 顯示密度 / 快捷設定 / 收起。進編輯模式會換成 加點 / 刪點 / 儲存 / 顯示密度 / 快捷設定
- **快捷設定面板** — 迴圈次數、速度、逐手勢補發、螢幕常亮、黑幕、計時器、工具列大小與不透明度,人在目標 app 裡就能改
- **頂部橫向播放面板** — 停止 / 暫停 / 迴圈次數 / 步驟進度 / 計時器
- **全螢幕標記畫布** — 序號準心與滑動軌跡,兼作錄製攔截層

## 編譯

本專案**不需要在本機安裝 Android Studio**。推上 GitHub 後 [Actions](.github/workflows/android.yml) 會自動編譯,到該次 run 的 Artifacts 下載 `app-debug.apk`。

本機若要編譯,需要 JDK 17 + Android SDK(compileSdk 35),然後:

```bash
gradle assembleDebug
```

註:repo 裡沒有 `gradle-wrapper.jar`(二進位檔無法從純文字環境產生),所以用系統的 `gradle` 而不是 `./gradlew`。用 Android Studio 開啟專案時它會自動補上 wrapper,屆時可把 CI 改成 `./gradlew`。

## 安裝與啟用

1. 安裝 `app-debug.apk`(需允許安裝未知來源)
2. 開啟 app → 依畫面指示前往 **設定 → 無障礙 → 觸控流** 開啟服務
3. 回到 app,打開「顯示懸浮工具列」

一般裝置只需要這一個開關。如果你的 ROM(小米 / 華為 / OPPO 等)擋掉了無障礙懸浮視窗,app 會提示你再開一個「顯示在其他應用上層」權限作為備援。

## 語系

介面支援**英文**(預設)與**正體中文**。跟隨系統語言,無需在 app 內切換。

新增字串請同時更新 `values/strings.xml` 與 `values-zh-rTW/strings.xml`,詳見 [CONTRIBUTING.md](CONTRIBUTING.md#使用者可見字串)。程式碼裡不得硬編碼任何使用者讀得到的文字。

## 已知限制

這些是無 root 方案的硬限制,不是待修的 bug:

1. **部分遊戲與金融 app 會擋掉注入的手勢** —— 它們會檢查 `FLAG_WINDOW_IS_OBSCURED`、`getToolType`,或直接偵測無障礙服務是否啟用。重播會沒有反應。無 root 無解。
2. **工具列與播放面板蓋住的區域,錄製時錄不到、播放時那一步會被吃掉。** Android 的觸控只會分派給最上層的 window。請把它們拖到空白處 —— app 會用斜線警示區提醒你。
3. **部分 app 會丟棄「被遮蔽」的觸控**(它們的 View 設了 `filterTouchesWhenObscured`)。只要有懸浮視窗蓋在觸控點上,那一下就會被那些 app 直接丟掉 —— 連你自己手指點也一樣。所以:
   - 待機與播放時,全螢幕標記畫布會**完全移除**,不影響任何 app
   - 錄製時那個 app 若會擋,**目前沒有解法**。試過在補發前把畫布移開或縮小,兩者都反而弄壞了原本正常的情況(座標偏移、手勢被系統取消),所以移除了
   - 「標記持續顯示」與「播放時蓋黑幕」這兩個設定需要全螢幕遮罩,**開著就會讓這類 app 忽略重播**,設定裡有寫明
4. **時序精度約 ±10~30ms**,受系統排程影響。要求毫秒級精準的場景不適用。
5. **跨機型只做線性座標縮放**,不做圖像識別。換一台解析度不同的手機,腳本可能會歪。
6. **錄製時畫面會有 100~200ms 頓挫**(逐手勢補發的代價),快速連續滑動會失準。設定裡可切換成「純盲錄」,代價是錄製時畫面完全不會前進。
7. **不支援文字輸入自動化。** 需要打字的地方插一個**暫停點**,腳本跑到那裡會停下來,你自己打完再按繼續。
8. **播放中偵測不到你手動碰螢幕**,所以沒有「碰到就自動暫停」的保護。請用音量下鍵或播放面板中斷。
9. **帶 `FLAG_SECURE` 的畫面**(銀行、密碼輸入)會隱藏所有懸浮視窗,注入手勢通常也會被擋。

## 中斷執行

- 播放面板的 ⏸ / ■
- **音量下鍵** = 暫停 / 繼續,**長按音量下 1 秒** = 停止

音量鍵只在播放中與暫停中攔截,待機與錄製時不影響你正常調音量。
